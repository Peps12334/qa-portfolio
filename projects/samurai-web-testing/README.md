# Samurai Web Application — Manual Testing

## Project Overview

This project contains a comprehensive manual testing of the **Samurai** food delivery web application.

The purpose of the project is to demonstrate a structured QA approach to testing a real-world web application, including test planning, functional testing, UI testing, responsive testing, exploratory testing, and defect reporting.

The application provides users with the ability to browse a food catalog, view product information, add products to a shopping cart, and place delivery orders.

## Testing Objectives

The main objectives of this project are:

* Verify that the core functionality works according to expected behavior.
* Identify functional and UI defects.
* Check the correctness of the main user flows.
* Verify application behavior in negative and boundary scenarios.
* Evaluate the responsive behavior of the application.
* Investigate application behavior using browser developer tools.
* Document identified defects using professional bug reports.
* Provide a final assessment of the tested application.
